# לוח ניהול IVR (Vite + React)

אפליקציית React (Vite) לניהול ובדיקה של שלוחות IVR של ימות המשיח. ניתן להזין מספר מערכת וסיסמה, לבחור שלוחה (ברירת המחדל 1/2), לקבל את רשימת הפריטים, לראות כמות קבצים ולהוריד קובץ בודד או את כולם ברצף.

## הפעלה מקומית

1. התקנת תלויות:
   ```bash
   npm install
   ```
2. הרצת שרת פיתוח:
   ```bash
   npm run dev
   ```
3. בנייה והפעלת Preview:
   ```bash
   npm run build
   npm run preview
   ```

> אם יש מגבלות רשת, הגדירו פרוקסי או רישום npm מתאים לפני `npm install`.

## קובצי תצורה חשובים

- `.env` (אופציונלי): הגדירו בו `VITE_YEMOT_API_BASE_URL` אם ברצונכם להחליף את כתובת ה-API ברירת מחדל (`https://www.call2all.co.il/ym/api`).
- `public/sample-data/map-export.json`: קובץ לדוגמה להשארת המידע שהיה קיים ברפוזיטורי המקורי.

## שימוש באפליקציה

1. למעלה בדף תמצאו שדות ברורים להזנת **מספר מערכת** ו**סיסמה**.
2. הגדירו את נתיב השלוחה (ברירת מחדל 1/2) ואת כתובת ה-API במידת הצורך.
3. לחצו על "בדיקת שלוחה" לקבלת הרשימה; או על "טעינת נתוני דמו" כדי לראות מבנה נתונים ללא חיבור API.
4. כפתור "הורדת כל הקבצים" ינסה להוריד ברצף את כל הקבצים; לצד כל פריט ניתן להוריד קובץ בודד.

### הצגת פרטי שלוחה עם טוקן

בדף הניהול ניתן להזין מספר מערכת, טוקן פעיל ונתיב שלוחה (למשל `ivr2:/1/2`) ולקבל את רשימת התיקיות והקבצים כפי שמוחזרת מ-`GetIVR2Dir` של Yemot. ניתן להדביק טוקן שנוצר באותו דף או להשתמש בטוקן קיים, ולראות גם תצוגת JSON מלאה לצורך ניפוי שגיאות.

### הורדות וקבצים

- אם ה-API מחזיר `downloadUrl` עבור כל פריט, הכפתורים משתמשים בו ישירות.
- אם לא קיימת `downloadUrl` אך קיים `path`, נבנה כתובת לפי התבנית: `<BASE_URL>/ivr/file?system=<מספר>&password=<סיסמה>&path=<נתיב>`.
- תצוגת JSON גולמי מוצגת בתחתית כדי לעזור לזהות מפתחות מותאמים.

## בדיקות וקוד
